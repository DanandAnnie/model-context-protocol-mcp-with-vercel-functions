# Change history

What shipped in `avatar-studio/`, one entry per feature or pass, in the order it landed, with the short commit hash of each change. Each entry ends with what an independent review of that commit found and where the fix landed, so a reader can see which guarantees are tested and why a piece of code looks the way it does.

The route reference is in [API.md](./API.md); the setup and feature overview is in the [README](../README.md).
